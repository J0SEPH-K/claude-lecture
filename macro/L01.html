INSTALL.

201 — Python(파이썬): 우리가 만들 프로그램의 언어

  1. python.org → Downloads → Windows 최신 버전
  2. Add python.exe to PATH 체크 ✅제일 많이 놓치는 단계
  3. Install Now
  4. PowerShell을 새로 열고 확인
python --version

Python 3.13.x처럼 숫자가 나오면 성공. Microsoft Store가 열리면 PATH 체크를 놓친 것입니다.

304 — 대화 2 · 이 폴더의 규칙 게시판

/init
CLAUDE.md에 이 프로젝트의 규칙을 추가해 줘.
- 나는 코딩 초보다. 모든 코드에 한국어 주석을 단다.
- 새 패키지를 설치하기 전에 무엇을 왜 설치하는지 먼저 말한다.
- 한 번에 한 기능만 만들고, 실행 방법을 알려 준다.
- 목표는 매크로가 허용된 게임용 매크로다.
  안티치트 회피·게임 메모리 조작은 쓰지 않는다.
CLAUDE.md

Claude가 이 폴더에서 일할 때마다 먼저 읽는 규칙

같은 말을 매번 반복하지 않아도 됩니다.

305 — 대화 3 · 연습용 과녁 게임 (계획 모드로)

매크로 연습용 게임을 target_game.py로 만들어 줘.
- tkinter로 600x400 창, 배경은 어두운 색
- 창은 항상 화면 (100, 100) 위치, 크기 고정
- 가운데 빨강·흰색 과녁(동심원)
  과녁을 클릭하면 점수 +1
- 왼쪽 위에 "점수: 0" 표시
- 창이 항상 다른 창보다 위에 뜨게

계획을 먼저 읽고,
그다음 승인

Shift + Tab으로 계획 모드 → 계획 읽기 → 승인 → python target_game.py

306 — 대화 4 · 첫 자동 클릭

autoclick.py를 만들어 줘.
- 실행하면 3, 2, 1 카운트다운을 하고,
  그때 마우스가 있는 위치를 기억해
- 그 위치를 0.3초 간격으로 20번 클릭
- 마우스를 화면 왼쪽 위 구석으로 옮기면
  바로 멈추게 (pyautogui FAILSAFE)
- 패키지 설치 전에는 나에게 먼저 물어봐
  1. 창 1: python target_game.py
  2. 창 2: python autoclick.py
  3. 3초 안에 마우스를 과녁 위로
  4. 손 떼고 점수 +20 확인 🎉
