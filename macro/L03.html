101 — 화면은 픽셀(pixel)의 바둑판

(0, 0) ──────────▶ X
  │
  │       ● (400, 300)
  │
  ▼
  Y
왼쪽 위가 출발점

X는 오른쪽, Y는 아래로 커짐

수학 그래프와 Y 방향이 반대입니다.

모니터가 여러 대라면

주 모니터 왼쪽 위 = (0, 0)

왼쪽 모니터는 X가 음수. 게임은 주 모니터에 띄웁니다.

102 — 화면 배율 125% · 150%가 좌표를 어긋나게 한다

눈금이 다른 자 두 개로 같은 점을 재면

진짜 자 · 1칸 = 1픽셀

(500, 400)

화면을 찍는 도구(mss)가 쓰는 자

늘어난 자 · 1칸 = 1.25픽셀

(400, 320)

배율을 모르는 프로그램에게 Windows가 건네주는 자

두 도구가 다른 자를 쓰면 매크로가 엉뚱한 곳을 보고, 엉뚱한 곳을 누릅니다.

(왼쪽, 위, 너비, 높이)

작게 찍을수록 빠릅니다. 한 점의 색만 필요하면 1×1로 찍습니다.

302 — 공통 도구함 screen.py

화면을 읽는 기능들을 screen.py라는 공통 도구 파일로 만들어 줘. 앞으로 만들 매크로가 모두 이 파일을 가져다 쓸 거야.
- 파일을 불러오는 순간 Windows DPI 인식을 켜서, 화면 배율이 125%·150%여도 좌표가 어긋나지 않게
- grab(region): mss로 화면을 찍어. region은 (왼쪽, 위, 너비, 높이), 없으면 주 모니터 전체
- pixel(x, y): 한 점의 색을 (R, G, B) 순서로 돌려줘
- color_close(rgb, target, tolerance): R, G, B 각각의 차이가 tolerance 이하면 True
- click(x, y), press(key): 클릭과 키 입력. pydirectinput이 설치돼 있으면 그걸 쓰고, 없으면 pyautogui를 써
  pyautogui FAILSAFE는 켜 둬. pydirectinput은 아직 설치하지 마
- 패키지를 설치하기 전에 무엇을 왜 설치하는지 먼저 말해 줘

설치 질문이 나오면: mss = 화면 사진을 빠르게 찍는 도구, numpy = 숫자 묶음을 다루는 도구 → Yes
