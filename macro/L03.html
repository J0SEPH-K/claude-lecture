3-2 — 지시하기

💬 Claude Code에 입력
화면을 읽는 기능들을 screen.py라는 공통 도구 파일로 만들어 줘.
앞으로 만들 매크로가 모두 이 파일을 가져다 쓸 거야.
- 불러오는 순간 Windows DPI 인식을 켜서 배율 125%·150%여도 좌표가 맞게
- grab(region): mss로 화면을 찍어. region은 (왼쪽, 위, 너비, 높이), 없으면 전체
- pixel(x, y): 한 점의 색을 (R, G, B) 순서로
- color_close(rgb, target, tolerance): 각각의 차이가 tolerance 이하면 True
- click(x, y), press(key): pydirectinput이 있으면 그걸, 없으면 pyautogui
  pyautogui FAILSAFE는 켜 둬. pydirectinput은 아직 설치하지 마
- 패키지를 설치하기 전에 무엇을 왜 설치하는지 먼저 말해 줘
- 다 만들면 pixel()이 제대로 되는지 짧게 시험해 봐
