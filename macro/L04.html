0:55 — 도구함에 그림 찾기

FIND.

screen.py + 스스로 시험

"다 됐어요" 대신 증거

3-1 — 지시하기

💬 Claude Code에 입력
screen.py에 그림 찾기 도구를 추가해 줘. OpenCV를 써.
- load_template(path): 그림 파일을 읽어. 한글 경로도 읽히게
- find_in_image(화면 그림, 찾을 그림, threshold): 가장 비슷한 곳의
  (가운데 X, 가운데 Y, 일치도). threshold보다 낮으면 None
  찾는 방식은 TM_CCOEFF_NORMED (일치도가 0~1)
- find(template_path, region=None, threshold=0.85): 화면(또는 region)을
  찍어서 찾고, 결과를 화면 전체 기준 좌표로
- grab()이 돌려주는 그림을 OpenCV에서 바로 쓸 수 있게
- 패키지를 설치하기 전에 무엇을 왜 설치하는지 먼저 말해 줘
opencv-python · numpy 설치 허락 → 이름 확인 → Yes

3-2 — Claude에게 스스로 시험시키기

💬 Claude Code에 입력
find_in_image()가 맞게 동작하는지 스스로 시험해 줘.
- 가짜 화면 그림(검은 바탕에 빨간 네모)을 만들고,
  빨간 네모를 잘라 찾을 그림으로 써
- 찾은 위치가 맞는지, 일치도가 0.99 이상인지
- 빨간 네모가 없는 그림에서는 None인지
- 시험 파일은 tests\test_find.py,
  결과를 표로 알려 줘
시험결과
있는 곳 찾기✅ 위치 일치 · 1.00
없는 곳✅ None
새 습관

"만들어 줘" + "스스로 시험해 줘"

말 대신 증거. 고칠 때마다 다시 돌리면 깨진 걸 바로 앎
