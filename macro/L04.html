202 — 도구함에 그림 찾기 추가

screen.py에 그림 찾기 도구를 추가해 줘. OpenCV를 써.
- load_template(path): 그림 파일을 읽어. 폴더나 파일 이름에 한글이 있어도 읽히게 해 줘
- find_in_image(화면 그림, 찾을 그림, threshold): 화면 그림 안에서 가장 비슷한 곳을 찾아
  (가운데 X, 가운데 Y, 일치도)를 돌려주고, 일치도가 threshold보다 낮으면 None
  찾는 방식은 TM_CCOEFF_NORMED (일치도가 0~1로 나오는 방식)
- find(template_path, region=None, threshold=0.85): 화면(또는 region 영역)을 찍어서
  위 함수로 찾고, 결과를 화면 전체 기준 좌표로 돌려줘
- grab()이 돌려주는 그림을 OpenCV에서 바로 쓸 수 있는 형식으로 맞춰 줘
- 패키지를 설치하기 전에 무엇을 왜 설치하는지 먼저 말해 줘

설치 질문: opencv-python = 그림 처리 도구 → Yes · region을 쓰면 영역의 왼쪽 위 좌표를 더해야 화면 좌표가 됩니다

203 — 찾을 그림 찍기: capture_template.py

capture_template.py를 만들어 줘.
화면의 일부를 잘라 '찾을 그림'으로 저장하는 도우미야.
- 실행: python capture_template.py target.png
  (이름을 안 주면 target.png)
- 3, 2, 1 카운트다운 뒤 마우스 위치를 '왼쪽 위'로,
  다시 3, 2, 1 뒤 마우스 위치를 '오른쪽 아래'로 기억
- 그 사각형을 screen.py의 grab()으로 찍어서 저장.
  한글 경로에도 저장되게
- 사각형이 너무 작으면(5픽셀 미만) 다시 하라고 알려 줘
  1. 게임을 find 모드로
  2. 과녁보다 살짝 바깥 왼쪽 위
  3. 살짝 바깥 오른쪽 아래
  4. target.png를 열어 확인과녁만 딱 들어가는 크기

403 — 그림 찾기의 함정

함정왜대처
해상도 · 배율 · UI 크기 변경그림 크기가 달라짐 (실험 C)설정 고정, 바뀌면 다시 찍기
반투명 · 배경이 비침뒤 배경이 바뀌면 그림도 바뀜비치지 않는 가운데만 작게
반짝임 · 애니메이션찍은 순간과 모양이 다름움직이지 않는 부분 고르기
마우스 올리면 바뀌는 버튼'불 들어온 모양'이 찍힘모서리를 살짝 바깥에서
한글 폴더 · 파일 이름OpenCV 기본 읽기가 조용히 실패우리 도구함은 한글도 읽게 만듦
전체 화면(독점) 모드찍으면 검게 나오는 게임이 있음창 모드 · 테두리 없는 창
