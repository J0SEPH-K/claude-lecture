202 — /clear → 계획 모드(Shift + Tab)로 지시

scenario.py를 만들어 줘. 시나리오(단계 목록)를 읽어서 차례로 실행하는 매크로 엔진이야.
- 단계 목록은 scenario.json에서 읽어 와. 다른 파일을 줄 수도 있게 해 줘.
  예: python scenario.py scenario_color.json
- 단계 종류는 6가지: find_click / wait_image / wait_color / click / key / wait
- 기다리는 단계마다 timeout(초)이 있고, 그 안에 못 찾으면 그 단계는 실패야.
- 실패한 단계는 retries 횟수만큼 다시 시도해. 그래도 실패하면 전체를 멈추고,
  그 순간의 화면을 logs 폴더에 시간이 들어간 이름의 그림으로 저장해.
- 시나리오 전체를 loops 횟수만큼 반복해. 0이면 F12를 누를 때까지 계속.
- F8은 시작/일시정지, F12는 끝.
- 단계마다 성공·실패를 화면과 logs/macro.log에 시간과 함께 기록해.
- 화면 읽기, 그림 찾기, 클릭, 키 입력은 새로 만들지 말고 screen.py에 있는 함수를 써.
계획을 먼저 보여 줘.

단계 6가지의 자세한 설명은 수업 자료 4번에 있습니다. 그대로 붙여 넣어도 됩니다.

501 — ① /clear → Claude가 나를 인터뷰한다

너는 게임 매크로 설계 전문가야. 내가 게임에서 자동으로 하고 싶은 "(작업 이름)"을
나 없이도 매크로가 똑같이 해낼 수 있도록 나를 인터뷰해 줘.
- 먼저 CLAUDE.md의 게임 규칙을 읽고, 이 작업이 규칙 안에 있는지부터 확인해 줘.
- 질문은 한 번에 1~2개씩만 해.
- 순서: 목적 → 시작할 때 화면 상태 → 단계별로 내가 누르는 것과 그때 보이는 것
  → 기다려야 하는 순간과 그 신호(그림·색) → 자주 생기는 예외(팝업, 로딩, 렉)
  → "잘 끝났다"는 화면 신호 → 몇 번 반복하고 언제 멈출지
- 내 답이 애매하면 화면에 정확히 무엇이 보이는지 다시 물어봐.
- 정보가 충분히 모였다고 판단되면 "인터뷰 완료"라고 말해.

작업은 1회차 숙제 "하고 싶은 일" 중 규칙 안에서 가장 작고 쉬운 것 하나 · 2회차 숙제의 좌표·색을 옆에

502 — ② 매뉴얼 + ③ 완료 체크리스트

인터뷰 내용을 docs/작업 매뉴얼 - (작업 이름).md로
정리해 줘. 형식:
1. 언제 쓰는가  2. 목적
3. 게임 규칙 확인  4. 시작 전 화면과 게임 설정
5. 준비물 (그림·좌표·색) — 없는 그림은 [캡처 필요]
6. 처리 순서 (단계 종류와 시간 제한까지)
7. 자주 생기는 실패와 대처
8. 매크로를 멈춰야 하는 상황
9. 완료 체크리스트
인터뷰에 없는 내용은 지어내지 말고 [확인 필요]로.
완료 체크리스트 = '다 됐다'고 볼 기준

☐ 실패하면 멈추고 logs/에 화면이 남는가?
☐ F8·F12가 되는가? (내가 확인)
☐ 게임 규칙에서 금지한 행동이 없는가?
