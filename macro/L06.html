2:15 — 시나리오 v1

V1.

작업 하나만

욕심내서 두세 개를 잇지 않습니다.

5-1 — 계획 모드로 지시

💬 Claude Code에 입력
docs/작업 매뉴얼 - (작업 이름).md를 읽고, 그 작업을 하는
scenario_game.json을 만들어 줘. scenario.py는 고치지 마.
- 매뉴얼의 처리 순서를 그대로 단계로. 그림은 templates 폴더의 것
- 기다리는 단계마다 매뉴얼에 적힌 시간 제한
- 처음 시험이니까 loops는 1, 재시도는 1
- 게임 창 영역만 찾게 region을 넣어 줘 (왼쪽 위와 크기는 매뉴얼에)
- 단계마다 왜 그 단계가 필요한지 한 줄씩 설명
- 다 만들면 완료 체크리스트로 확인하고 결과를 표로

5-2 — 계획과 체크리스트 표 읽기

{
  "name": "우편함 보상 받기",
  "loops": 1, "retries": 1, "threshold": 0.85,
  "steps": [
    {"do": "find_click", "image": "templates/mail_icon.png", "timeout": 5},
    {"do": "find_click", "image": "templates/receive_all.png", "timeout": 5},
    {"do": "wait_image", "image": "templates/received_ok.png", "timeout": 10},
    {"do": "key", "key": "esc"}
  ]
}
