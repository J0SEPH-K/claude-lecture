0:20 — 왜 조종판인가

PANEL.

명령어 대신 버튼으로

버튼과 칸으로 쓰는 화면을 GUI(그래픽 사용자 화면)라고 합니다. 우리는 조종판이라고 부릅니다.

101 — 비유: 시동 거는 법

PowerShell → cd → python scenario.py scenario.json. 횟수를 바꾸려면 json 파일을 열어서 고치기.

104 — 계획 모드(Shift + Tab)로 지시

control_panel.py를 만들어 줘. 매크로를 버튼으로 쓰는 조종판이야.
- tkinter로 작은 창. 항상 다른 창보다 위에 뜨게
- [시나리오 열기] 버튼으로 json 파일을 고르고, 고른 파일 이름을 옆에 표시
- "반복 횟수" 입력 칸 (0이면 무한 반복)
- [▶ 시작] [⏸ 일시정지] [■ 정지] 버튼
- 지금 상태(대기 중 / 실행 중 / 일시정지 / 정지 / 끝)를 글자와 색으로 표시
- 아래 기록 칸에 매크로 기록이 실시간으로. logs/macro.log에도 그대로 남게
- F8(시작/일시정지)과 F12(정지) 단축키도 그대로 동작
- 매크로 엔진은 새로 만들지 말고 scenario.py의 실행 코드를 그대로 가져다 써
- 매크로는 별도 스레드에서 돌려서, 실행 중에도 창이 멈추지 않게 해 줘
계획을 먼저 보여 줘.

401 — 실행 파일 만들기

control_panel.py를 더블클릭으로 여는 실행 파일(.exe)로 만들고 싶어.
- PyInstaller를 써. 설치하기 전에 나에게 먼저 물어봐
- 파일 하나로(one-file), 검은 PowerShell 창은 뜨지 않게(no console)
- 이름은 MacroPanel
- 만드는 명령은 build_exe.bat에 적어 둬서 다음에도 더블클릭으로 다시 만들 수 있게
- 시나리오 파일과 찾을 그림은 exe 안에 넣지 말고, exe 옆에 두고 쓰는 방식으로
- logs 폴더(기록, 실패 화면)도 exe가 있는 폴더에 생기게
- build, dist 폴더는 저장(커밋)하지 않게 .gitignore에 추가해 줘
- 다 만들면 결과 파일 위치와, 무엇을 어디로 복사해야 하는지 알려 줘

⚠️ 코드를 고친 뒤에는 build_exe.bat을 다시 실행해야 exe에 반영됩니다.

402 — Windows가 경고하면: 침착하게

왜 뜨나

서명 없는 새 프로그램

Windows가 처음 보는 파일이라 조심하는 것입니다. 내 파일이 위험하다는 뜻은 아닙니다.

이렇게

내가 만든 게 확실할 때만

"추가 정보 → 실행". 남에게 받은 exe에는 절대 하지 않습니다. 격리되면 되살리지 않고 run.bat으로.

하지 않는 것

보안 기능 끄기

백신·실시간 보호 끄기, 검사 제외 등록은 하지 않습니다. exe를 남에게 나눠 주지도 않습니다.
