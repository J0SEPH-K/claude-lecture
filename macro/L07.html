0:55 — 조종판

DRIVE.

control_panel.py

창이 굳지 않게: 일꾼 두 명

3-1 — 계획 모드로 지시

💬 Claude Code에 입력
control_panel.py를 만들 계획을 세워 줘. 매크로를 버튼으로 쓰는 조종판이야.
- tkinter로 작은 창. 항상 다른 창보다 위에 뜨게
- [시나리오 열기] 버튼으로 json 파일을 고르고, 파일 이름을 옆에 표시
- "반복 횟수" 입력 칸 (0이면 무한 반복)
- [▶ 시작] [⏸ 일시정지] [■ 정지] 버튼
- 상태(대기 중 / 실행 중 / 일시정지 / 정지 / 끝)를 글자와 색으로
- 아래에 기록 칸: 기록이 실시간으로 한 줄씩. logs/macro.log에도 남게
- F8(시작/일시정지)과 F12(정지) 단축키도 그대로
- 엔진은 새로 만들지 말고 scenario.py의 실행 코드를 그대로 가져다 써
- 매크로는 별도 스레드에서 돌려서, 실행 중에도 창이 멈추지 않게
계획에 "scenario.py를 고친다"가 있으면 무엇을 왜 물어보기

SAVE.

/save · /export

자주 하는 일은 명령 하나로

8-1 — 나만의 명령 /save 만들기

💬 Claude Code에 입력
이 프로젝트에서 쓸 나만의 명령 /save 를 만들어 줘.
- /save 를 치면: 바뀐 파일을 보여 주고(git status),
  무엇이 바뀌었는지 한 줄로 요약한 이름을 지어서
  저장하기 전에 그 이름을 확인받고, 확인하면 저장
- /save 뒤에 글을 붙이면 그 글을 저장 이름으로
- logs, build, dist 폴더는 저장하지 마
- 명령 파일은 이 프로젝트의 .claude 폴더 안에
  1. /exit → claude -c새 명령을 읽게
  2. /sa까지 치면 목록에 /save
💬 Claude Code에 입력
/save README와 run.bat 추가
바뀐 파일 → 이름 확인 → Yes → 저장

다른 예: /check = 체크리스트로 지금 상태 확인

8-2 — 대화 내보내기: /export
